# P0.2 符号回归可行性报告（PySR go/no-go）

> 阶段：Phase 0 技术预研 | 日期：2026-08-27
> 项目：pymo — 物理世界 AI 推演模型

## 一、环境说明

**PySR 无法在本机直接评估**：PySR 依赖 Julia，而 Julia 官方二进制仅托管于 AWS S3。本网络环境对 S3 限速严重（实测 280MB 下载仅 3.9MB 后超时）；国内镜像（清华/USTC）不托管 Windows Julia 二进制。winget 安装亦超时未完成。

**按计划止损条款改用 gplearn**（纯 Python 遗传编程符号回归），回答相同的 go/no-go 问题：符号回归能否从数据中重新发现简单物理定律。

## 二、实测结果

流水线：**GP 发现结构 → 最小二乘系数精修**（gplearn 无内置常数优化，PySR 用 BFGS 实现此步）。

| 系统 | 真实值 | 恢复值 | 判定 |
|------|--------|--------|------|
| 自由落体 y=y0-½gt² | g=9.81, y0=10.0 | g=9.810, y0=10.000 | **PASS** |
| 弹簧振子 A·cos(ωt) | A=1.0, ω=2.0 | A=1.000, ω=2.000 | **PASS** |
| 单摆 θ0·cos(ωt) | A=0.2, ω=3.0 | A=0.200, ω=3.000 | **PASS** |

## 三、关键发现（重要）

1. **结构发现可行**：GP 能正确找到函数形式（自由落体→二次式、振荡→三角式）。
2. **系数发现需常数优化**：纯 gplearn 的随机常数不匹配数据量级（实测 free-fall 结构正确但 R²=-410，因系数差 6 倍）。PySR 通过内置 BFGS/Adam 常数优化解决——这正是 PySR 相对朴素 GP 的核心优势。
3. **完整流水线可靠**：结构发现 + 系数精修后，三个系统的物理常数全部精确恢复（误差 <0.1%）。

## 四、go/no-go 结论

**判定：GO — 符号回归可行，AI 层采用符号回归。**

- AI 层具备从时序数据中发现简单解析物理定律的能力（已实证恢复 g、ω）。
- 必须配置**常数优化**机制：优先 PySR（自带 BFGS）；若 PySR 环境不可用，用 gplearn 结构发现 + scipy 最小二乘/网格扫描系数精修（本测试已验证此替代方案有效）。

## 五、风险与对策

1. **PySR/Julia 部署**：需在网络友好环境安装 Julia。对策：AI 层设计为**符号回归后端可插拔**，PySR 与 gplearn+精修双后端，运行时选择。
2. **复杂系统退化**：三体以上混沌系统符号回归难度上升。对策：阶段四引入 PINN/神经网络兜底（符合计划止损条款）。
3. **局部最小值**：振荡类系数拟合易陷局部极小。对策：粗网格扫描初始化（本测试已验证有效）。
