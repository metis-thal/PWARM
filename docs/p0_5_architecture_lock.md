## 三、架构决策要点

1. **物理内核自研**：拒绝 Pymunk/Bullet 黑盒，保证方程级访问与守恒律强制。P0.4 已证明自研 Verlet 数值稳定性达机器精度。
2. **AI 层符号回归可插拔**：后端抽象（PySR / gplearn+scipy精修），运行时选择。规避 Julia 网络部署风险。
3. **渲染层 PyVista**：原生 numpy 集成 + 物理场云图内建 + 交互相机。
4. **环境基线**：Python 3.10（避开 3.14 wheel 不兼容），pip 阿里云镜像（规避 files.pythonhosted.org 限速）。
